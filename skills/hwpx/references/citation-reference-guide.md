# 인용·참고문헌·표기 규범 가이드 (citation-reference-guide)

> APA 7th 기반 참고문헌 표기, 통계 표기, 표·그림 규범의 상세 레퍼런스.
> academic-defaults.md의 인용 섹션 확장판. 필요할 때 참조한다.

## Part 1: APA 7th 참고문헌 표기

### 국내 논문

```
저자(연도). 논문 제목. 학술지명, 권(호), 시작쪽-끝쪽.
https://doi.org/...

예)
홍길동(2023). 학부모 스트레스가 교사 직무소진에 미치는 영향. 교육학연구, 61(2), 45-72.
  https://doi.org/10.29318/KCI.20230600
홍길동, 김철수(2022). 교직만족도와 소진의 관계. 교육심리연구, 36(1), 1-25.
```

- 저자가 3인 이상: 모두 나열
- 학술지 권·호: 권은 이탤릭(또는 굵게), 호는 괄호 안 일반체
- 한국어 논문은 DOI가 없으면 생략 가능

### 국내 저서

```
저자(연도). 책 제목. 출판사.

예)
홍길동(2021). 구조방정식 모형의 이해와 적용. 학지사.
홍길동, 김철수(2020). 교육통계학(3판). 교육과학사.
```

### 번역서

```
원저자(원저 연도/번역 연도). 번역 제목 (역자명, 역). 출판사.

예)
Kline, R. B.(2011/2016). 구조방정식 모형의 원리와 실제 (이현숙, 김수진 역). 학지사.
```

### 학위논문

```
저자(연도). 논문 제목 [석사/박사학위논문, 대학교명].
  학술DB명. https://...

예)
홍길동(2023). 교사 소진의 선행변인과 결과변인에 관한 연구 [박사학위논문, 한국외국어대학교].
  RISS. https://www.riss.kr/...
```

### 기관 보고서

```
발행기관(연도). 보고서 제목. 기관명.
  https://...

예)
한국교육개발원(2024). TALIS 2024 한국 결과 보고서. 한국교육개발원.
OECD(2024). TALIS 2024 Technical Report. OECD Publishing.
  https://doi.org/10.1787/talis-2024-en
```

## Part 2: 영문 참고문헌 표기 (APA 7th)

### 저널 논문

```
저자성, 이니셜., & 저자성, 이니셜. (연도). 논문 제목. 학술지명, 권(호), 쪽-쪽.
  https://doi.org/...

예)
Bakker, A. B., & Demerouti, E. (2007). The job demands-resources model: State of the art.
  Journal of Managerial Psychology, 22(3), 309–328.
  https://doi.org/10.1108/02683940710733115

Hu, L. T., & Bentler, P. M. (1999). Cutoff criteria for fit indexes in covariance structure
  analysis: Conventional criteria versus new alternatives.
  Structural Equation Modeling, 6(1), 1–55.
  https://doi.org/10.1080/10705519909540118
```

규칙:
- 저자 20명까지 모두 표기; 21명 이상은 첫 19명 표기 후 `…` 삽입, 마지막 저자 표기
- 논문 제목: 첫 단어와 고유명사만 대문자
- 학술지명: 주요 단어 대문자 (Title Case)
- 권은 이탤릭·호는 괄호 일반체 (실제 문서에서 이탤릭 적용)

### 단행본

```
저자성, 이니셜. (연도). 책 제목 (판수 ed.). 출판사.
  https://doi.org/...

예)
Kline, R. B. (2016). Principles and practice of structural equation modeling (4th ed.).
  Guilford Press.
```

### 편저 내 챕터

```
저자성, 이니셜. (연도). 챕터 제목. In 편저자 이니셜. 성 (Ed./Eds.), 책 제목 (pp. 쪽-쪽).
  출판사.

예)
Preacher, K. J. (2015). Advances in mediation analysis. In T. D. Little (Ed.),
  Oxford handbook of quantitative methods (Vol. 2, pp. 458–485). Oxford University Press.
```

### 데이터셋

```
저자/기관 (연도). 데이터셋 제목 (버전) [Data set]. 저장소.
  https://doi.org/...

예)
OECD (2024). TALIS 2024 international dataset (Version 1.0) [Data set]. OECD.
  https://doi.org/10.1787/...
```

### R 패키지

```
저자성, 이니셜. (연도). 패키지명: 설명 (R 패키지 버전 X.X.X) [Computer software].
  https://CRAN.R-project.org/package=패키지명

예)
Rosseel, Y. (2012). lavaan: An R package for structural equation modeling.
  Journal of Statistical Software, 48(2), 1–36.
  https://doi.org/10.18637/jss.v048.i02
```

### DOI 표기 규칙

```
현행 형식 (APA 7th): https://doi.org/10.xxxx/...
구형 형식 (사용 금지): doi:10.xxxx/...
DOI 없는 경우: URL 생략 가능 (국내 학술지는 학술지명 + 권호만으로 식별 가능)
```

## Part 3: 통계·숫자 표기 상세

### 기본 원칙

- **0~1 사이 값**: 앞 0 생략 (β = .47, p = .032, R² = .23)
- **1 이상 값**: 소수점 앞 0 표기 (M = 3.10, SD = 0.99, F = 4.23)
- **음수**: 앞 0 표기 (β = -.20)
- 소수점 자릿수: 통일 (보통 소수 둘째 자리; p값은 셋째 자리)

### 검정통계량

```
t(df) = x.xx, p = .xxx
F(df1, df2) = x.xx, p = .xxx
χ²(df, N = n) = x.xx, p = .xxx
z = x.xx, p = .xxx

예)
t(98) = 2.31, p = .023
F(1, 194) = 8.45, p = .004
χ²(3, N = 120) = 7.82, p = .050
```

### 경로계수·효과크기

```
표준화 계수:    β = .47, SE = .06, p < .001
비표준화 계수:  b = 0.31, SE = 0.05, 95% CI [0.21, 0.41]
간접효과:       indirect = 0.137, 95% CI [0.112, 0.164]
효과크기:       Cohen's d = 0.62, η² = .08, f² = .12
```

### 모형 적합도

```
CFI = .997, TLI = .994, RMSEA = .038 [.012, .051], SRMR = .015
```

### 신뢰구간

```
95% CI [하한, 상한]
Bootstrap 95% CI [.112, .164]
```

### 유의수준 표기

```
* p < .05, ** p < .01, *** p < .001
† p < .10 (경계 유의)
```

## Part 4: 표·그림 규범

### 표 (Table)

```
표 번호·제목: 표 위에 위치, 굵게 처리
  표 1
  변수별 기술통계 및 상관관계 (N = 1,991)

표 본문: 일반 체, 선은 상단·하단·헤더 아래 수평선만 사용 (APA 스타일)

표 아래 주석 (Note.):
  Note. M = 평균; SD = 표준편차.
  *** p < .001.
  출처: 홍길동(2023), p. 45에서 수정.
```

### 그림 (Figure)

```
그림 번호·제목: 그림 아래에 위치
  그림 1
  학부모 스트레스와 교직후회의 관계에서 정서적 소진의 매개효과 모형

그림 아래 주석:
  Note. 표준화 경로계수. * p < .05, ** p < .01, *** p < .001.
  점선 = 직접효과; 실선 = 간접효과 경로.
```

### 번호 체계

- 표·그림 모두 본문 등장 순서대로 번호 부여
- 부록의 표·그림은 표 A1, 그림 A1 등으로 별도 표기

## Part 5: 학위논문 형식 참고 (format.md 작성 시 사용)

> 특정 대학교 규정이 있으면 해당 규정 우선. 아래는 일반적 기준.

### 여백·제본

| 항목 | 값 |
|------|----|
| 좌측 | 35mm (제본 여유) |
| 상·하·우 | 25mm |
| 머리말·꼬리말 | 15mm |

### 장·절·항 번호 체계

```
제1장 서론                  ← 장 (Chapter)
  제1절 연구의 필요성과 목적  ← 절 (Section)
    1. 연구 배경             ← 항
      가. 세부 내용          ← 목
        1) 더 세부적 내용    ← 세목
```

### 초록 규격

| 항목 | 기준 |
|------|------|
| 국문초록 | 600자 내외 |
| 영문초록 (Abstract) | 250단어 내외 |
| 키워드 | 국문·영문 각 5개 내외 |
| 위치 | 본문 앞 (목차 앞 또는 뒤) |

### 각주·미주

- 학위논문은 각주(footnote) 허용; 학술지는 불허하는 경우 多
- APA 7th: 각주는 내용 보충에만 사용; 인용 목적 각주 금지

### 목차 번호 예시

```
국문초록 ··················· i
목차 ························ iii
표 목차 ····················· v
그림 목차 ··················· vi
제1장 서론 ·················· 1
  제1절 연구의 필요성과 목적 · 1
  제2절 연구 문제 ··········· 8
  제3절 용어 정의 ··········· 10
...
참고문헌 ···················· 85
부록 ························ 92
Abstract ···················· 97
```
