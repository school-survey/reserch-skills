# 학술 문서 기본값 가이드 (academic-defaults)

> format.md가 없을 때 항상 적용되는 기본 학술 문서 규격이다.
> 프로젝트별 format.md가 있으면 이 파일보다 format.md가 우선한다.

---

## 1. 문서 구조 (기본)

프로젝트 전용 format.md가 없을 때 아래 순서를 기본으로 사용한다:

```
제목 (논문 제목 — 굵게, 가운데 정렬)
저자 및 소속 (필요 시)
국문초록 + 키워드
Ⅰ. 서론
Ⅱ. 이론적 배경 / 문헌검토
Ⅲ. 연구방법
Ⅳ. 연구결과
Ⅴ. 논의 및 결론
참고문헌
(부록 — 필요 시)
```

섹션이 단순한 경우(초안·보고서 등):
```
제목
Ⅰ. [섹션명]
Ⅱ. [섹션명]
...
참고문헌
```

## 3. 글꼴·크기·줄간격 기본값

| 요소 | 기본값 |
|------|--------|
| 본문 | 바탕 또는 신명조, 11pt |
| 섹션 제목 (Ⅰ. Ⅱ. …) | 굵게, 13pt |
| 하위 제목 (1. 2. …) | 굵게, 12pt |
| 그 이하 (가. 나. …) | 11pt |
| 줄간격 | 160~180% |
| 참고문헌 | 10.5pt, 줄간격 140% |

python-docx 기준:
```python
from docx.shared import Pt, Inches
section.left_margin = section.right_margin = Inches(0.98)   # 25mm
section.top_margin  = section.bottom_margin = Inches(0.98)
# 본문 run.font.size = Pt(11)
# 줄간격 p.paragraph_format.line_spacing = Pt(18)  # ≈160%
```

HwpxDocument.new() 기준 (Python 3.10+):
```python
from hwpx import HwpxDocument
doc = HwpxDocument.new()
doc.add_paragraph("제목", para_pr_id_ref=0)   # 스타일은 ID 참조
doc.save_to_path("output.hwpx")
```

## 4. 제목 계층 체계

한국 학술지 관행:

```
Ⅰ. 대제목          ← bold 13pt, 문단 위 18pt
  1. 중제목         ← bold 12pt, 문단 위 12pt
    가. 소제목      ← 11pt, 문단 위 6pt
      1) 세부 항목  ← 11pt, 들여쓰기
```

## 5. APA 인용 기본값 (항상 적용)

format.md에 다른 인용 방식이 명시되지 않으면 APA 7th를 따른다.

### 본문 내 인용

```
단일 저자:       홍길동(2023) 또는 (홍길동, 2023)
두 저자:         홍길동과 김철수(2022) 또는 (홍길동, 김철수, 2022)
세 저자 이상:    홍길동 등(2021) 또는 (홍길동 등, 2021)
영문 단일:       Smith(2020) 또는 (Smith, 2020)
영문 두 저자:    Smith and Jones(2019) 또는 (Smith & Jones, 2019)
영문 세 저자+:   Smith et al.(2018) 또는 (Smith et al., 2018)
재인용:          (원저자, 연도; 재인용: 인용저자, 연도, p. 쪽)
쪽 번호:         (홍길동, 2023, p. 15) 또는 (홍길동, 2023, pp. 15-17)
```

### 참고문헌 기본 표기 (상세는 citation-reference-guide.md 참조)

```
국내 논문:
  홍길동(2023). 논문 제목. 학술지명, 권(호), 시작쪽-끝쪽.
  https://doi.org/...

영문 논문:
  Smith, J. A., & Jones, B. C. (2022). Article title. Journal Name,
    45(3), 123–145. https://doi.org/...
```

## 6. 학술 문체 원칙 (항상 적용)

### 지켜야 할 것

- **수치로 불확실성 표현**: "3개 연구 중 2개에서 유의한 효과를 확인하였다"
  → "연구들이 효과를 시사하는 것으로 보인다" 금지
- **구체적 지칭**: "선행연구에 따르면" 대신 "홍길동(2023)은"
- **단락 구조**: 주제문 → 근거(인용·수치) → 해석·연결
- **능동 서술 우선**: "분석하였다", "확인하였다" — "분석되었다" 절제

### 피해야 할 것

| 회피 표현 | 대체 |
|-----------|------|
| 다양한 연구에서 | 구체적 연구명·수 명시 |
| 중요한 시사점을 가진다 | 구체적으로 어떤 시사점인지 서술 |
| 또한, 더불어, 나아가 | 논리 관계가 자명하면 삭제 |
| ~할 수 있을 것으로 생각된다 | ~한다 / ~인 것으로 확인되었다 |
| 여러 선행연구 | 해당 연구 직접 인용 |

## 7. 통계 표기 기본값

```
경로계수:   β = .47, SE = .06, p < .001
상관:       r = .41, p < .001
신뢰구간:   95% CI [.11, .16]
적합도:     CFI = .997, RMSEA = .038, SRMR = .015
효과크기:   d = 0.62, η² = .08
유의수준:   * p < .05, ** p < .01, *** p < .001
```

규칙:
- 0~1 사이 수치는 앞 0 생략: β = .47 (O), β = 0.47 (X)
- p 값은 정확값 보고 원칙: p = .032 (O), p < .05만 쓰는 것 비권장
- 단, p < .001은 그대로 사용

## 9. format.md 작성 가이드

프로젝트 폴더에 `format.md`를 만들어 이 파일을 override한다.
최소한 아래 항목을 명시하면 충분하다:

```markdown
# [프로젝트명] 형식 가이드

## 투고 대상
- 학술지명: 예) 교육학연구 (한국교육학회)
- 또는: 박사학위논문 (한국외국어대학교)

## 여백
- 좌: 35mm (제본) / 나머지: 25mm

## 글꼴
- 본문: 신명조 10.5pt
- 줄간격: 180%

## 제목 체계
- 제1장 / 제1절 / 1. / 가. / 1)

## 인용 방식
- APA 7th (기본) 또는 특정 학술지 스타일

## 특이사항
- 초록: 국문 600자 이내, 영문 250단어 이내
- 키워드: 5개
```
