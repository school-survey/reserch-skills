# 양적 연구 디벨롭 가이드

> 설문조사·패널데이터 분석·실증 연구를 위한 디벨롭 가이드.
> 스킬의 기본 설계는 질적 연구 편향이 있으므로, 양적 연구에서는 이 문서를 적극 참조한다.
>
> 다루는 범위:
> 1. 횡단 설문조사 (자체 수집)
> 2. 2차 데이터 분석 — 대규모 패널·횡단 데이터 (TALIS, PISA, KELS 등)
> 3. 종단 데이터 분석
> 4. 실증·실험 연구

## 양적 연구 특유의 디벨롭 흐름

질적 연구가 **질문 → 방법 → 참여자**로 진행된다면, 양적 연구는 다음 순서로 진행된다.

1. **데이터 가용성 확인** (자체 수집 vs 2차 데이터)
2. **변인과 측정 정의**
3. **분석 모델 선택**
4. **가설 설정 또는 탐색적 질문 설정**
5. **표본 크기·검정력 점검**
6. **분석 수행**

**중요**: 양적 연구에서 가장 흔한 실패는 **"데이터가 없거나 부적합한데 분석 계획부터 세우는 것"** 이다. 디벨롭 초기에 데이터 가용성을 반드시 확인한다.

## 첫 질문: 어떤 데이터를 쓰는가?

사용자가 양적 연구를 하겠다고 하면 가장 먼저 이걸 묻는다.

### 유형 1: 자체 설문조사 수집

- 표본 프레임(sampling frame)이 존재하는가?
- 접근 가능한 표본 풀은 얼마인가?
- 수집 방법은? (온라인, 대면, 전화)
- 수집 기간은?
- 측정 도구는 기존 것을 쓰는가 새로 만드는가?
- IRB 승인 필요한가?

### 유형 2: 대규모 2차 데이터 활용

(TALIS, PISA, KELS, KEDI 종단연구, KOSIS 등)

- 어느 데이터를 쓰는가?
- 해당 데이터의 접근 권한(사용 승인)이 있는가?
- 데이터의 표본 설계를 이해하고 있는가? (가중치, 층화, 군집)
- 본인 연구질문에 맞는 변인이 데이터에 포함되어 있는가?
- 결측치 비율을 확인했는가?

### 유형 3: 행정 데이터 / 빅데이터

- 데이터 접근 협약이 있는가?
- 개인정보 처리 방침은?
- 데이터 정제에 드는 시간을 과소평가하지 않았는가?

**디벨롭 협업자로서의 원칙**: 데이터가 확보되지 않은 상태에서 분석 모델 논의로 넘어가지 않는다. "데이터는 확보되셨나요? 아니면 지금 논의하는 건 가설적 설계인가요?"를 명확히 한다.

## 설문지 문항 디벨롭

### 문항 설계 시 필수 점검

설문지를 새로 만들거나 기존 것을 수정할 때 다음을 확인한다.

#### C1. 측정하려는 구성개념(construct)의 정의

- 측정하려는 개념을 **한 문장으로 정의**할 수 있는가?
- 그 정의에 사용된 용어들이 모호하지 않은가?
- 기존 문헌에서 이 개념을 어떻게 정의하고 측정해왔는가?

#### C2. 기존 척도 검토

- 이미 검증된 척도가 있는가? 있다면 왜 쓰지 않는가?
- 있다면 타당도·신뢰도 지표는 어떠한가?
- 한국어 번역·타당화 버전이 있는가?

**원칙**: 충분한 이유 없이 새 척도를 만들지 않는다. 연구자가 "내가 직접 문항을 만들겠다"고 하면, 그 이유가 타당한지 반드시 검토한다. 대부분의 경우 기존 척도가 더 나은 선택이다.

#### C3. 문항의 질 점검 체크리스트

각 문항에 대해 다음을 점검한다.

- **이중질문(double-barreled)**: 한 문항에 두 개의 질문이 섞여 있지 않은가?
  - 나쁜 예: "이 수업은 재미있고 유익했다" (재미와 유익은 별개)
- **유도성 질문(leading question)**: 특정 답을 유도하는 표현은 없는가?
  - 나쁜 예: "대부분의 학자들이 동의하는 바와 같이, ~인가?"
- **이중부정**: 부정문 안에 부정어가 또 있지 않은가?
- **모호한 용어**: "자주", "가끔", "많이" 같은 주관적 빈도어가 구체적 기준 없이 쓰이지 않는가?
- **응답자 능력 초과**: 응답자가 실제로 알 수 없는 내용을 묻지 않는가?
- **민감성**: 사회적 바람직성 편향(social desirability bias)을 유발하지 않는가?
- **사전 지식 가정**: 응답자가 모를 수 있는 전문 용어를 사용하지 않는가?

#### C4. 응답 척도 점검

- **척도 수준**: 리커트 5점/7점, 빈도 측정, 범주 등 중 적절한가?
- **중립 응답 처리**: 중립 옵션을 둘 것인가 뺄 것인가? (연구 목적에 따라)
- **역문항 포함 여부**: 반응 편향 통제를 위한 역문항을 포함할 것인가?
- **응답 척도 일관성**: 문항들 간에 척도가 섞이지 않는가?

#### C5. 문항 수와 응답 부담

- 예상 응답 시간은? (10분 초과 시 응답률 급락)
- 응답자의 집중력 유지 가능한가?
- 핵심 문항과 덜 중요한 문항의 균형은?

### 문항 적절성 사전 검증 절차

설문지 완성 전에 다음을 반드시 거친다.

1. **전문가 내용 타당도 검증 (Content Validity)**
   - 해당 분야 전문가 3~5명에게 문항 적절성 평가 요청
   - 각 문항이 측정하려는 구성개념을 얼마나 잘 대표하는지 평가 (CVR, CVI 산출)

2. **예비조사 (Pilot Test)**
   - 실제 응답 대상과 유사한 집단 20~30명에게 시험 시행
   - 응답 시간, 이해도, 빠진 선택지 등 피드백 수집
   - 필요시 인지 면담(cognitive interview)으로 응답자의 해석 과정 탐색

3. **요인분석 (Factor Analysis)**
   - 탐색적 요인분석(EFA)으로 문항 구조 확인
   - 이후 별도 표본으로 확인적 요인분석(CFA)
   - 요인 적재량, 교차 적재, 설명 분산 등 점검

4. **신뢰도 검증**
   - Cronbach's α (단일 시점 내적 일관성)
   - 검사-재검사 신뢰도 (시간적 안정성)
   - 문항-전체 상관

### 디벨롭 대화에서 설문지가 나올 때

사용자가 "설문지를 만들었는데 검토해줘"라고 하면 다음 순서로 대응한다.

1. 먼저 측정하려는 구성개념의 정의를 확인
2. 기존 척도 검토 여부 확인
3. 문항 하나씩 C3 체크리스트 적용 (무비판적으로 칭찬하지 않음)
4. 응답 척도와 문항 수 점검
5. 검증 계획 확인 (전문가 검토·예비조사 예정인지)

각 단계에서 문제가 발견되면 구체적으로 지적한다. "이 문항은 이중질문입니다. '재미'와 '유익'을 분리해서 두 문항으로 나누세요"처럼.

## 패널데이터·2차 데이터 분석 디벨롭

### 대규모 2차 데이터 활용의 특수성

TALIS, PISA, KELS, KEDI 종단연구, 청소년 패널 등을 활용할 때, 자체 수집과는 다른 디벨롭 절차가 필요하다.

#### D1. 데이터 이해 선행

분석에 들어가기 전에 다음을 확인한다.

- **표본 설계**: 어떻게 표집되었는가? (층화, 군집, PPS 등)
- **가중치**: 어떤 가중치가 제공되며 언제 사용하는가?
- **결측치 패턴**: 무작위 결측인가, 체계적 결측인가?
- **코드북**: 변인 코딩이 본인이 해석한 대로인가?
- **조사 주기와 시점**: 시점별 문항 차이가 있는가?

**흔한 실수**: 가중치를 무시하고 분석하거나, 복합 표본 설계를 무시한 단순 분석으로 표준오차를 과소 추정하는 것.

#### D2. 연구질문-데이터 정합

- 본인 연구질문이 요구하는 변인이 해당 데이터에 **모두** 있는가?
- 있다면 그 측정이 본인이 원하는 개념과 **정확히** 일치하는가?
- 근사적 대체(proxy)만 가능하다면 그 한계는 무엇인가?

**함정**: 데이터에 있는 변인에 맞춰 연구질문을 억지로 변형하는 것. 이러면 "데이터 기반 연구"가 아니라 "데이터에 포획된 연구"가 된다.

#### D3. 문항 적절성 분석 (2차 데이터)

이미 수집된 데이터라도, 활용 전 문항의 질을 점검한다.

- **해당 문항의 원래 목적**과 본인의 연구 목적이 일치하는가?
- 해당 문항이 본래 측정하려던 것과 본인이 해석하는 것이 일치하는가?
- 문항의 문화적 맥락(해당 조사의 국가별 차이)을 고려했는가?

TALIS나 PISA 같은 국제 조사의 경우, 문항의 국가 간 측정 동등성(measurement invariance) 문제가 중요하다. 한국 데이터만 쓰더라도 원래 척도의 국제 비교 맥락을 이해해야 한다.

#### D4. 다층 구조 고려

교사/학생 데이터는 대개 **다층 구조**를 가진다.

- 학생 ← 학급 ← 학교 ← 국가
- 교사 ← 학교 ← 지역

다층 구조를 무시하고 단순 회귀를 하면 통계적 가정 위반이다.

- 다층모형(HLM, Multilevel Model) 필요 여부 확인
- 급내상관계수(ICC) 점검
- 상위 수준 변수의 영향 고려

## 변인 간 관계 탐색 디벨롭

### 관계 유형 분류

양적 연구에서 변인 간 관계를 탐색할 때, 연구자가 **어떤 관계를 주장하려는지** 분명히 해야 한다.

| 관계 유형 | 설명 | 적절한 분석 |
|----------|------|-----------|
| 상관 | 두 변인이 함께 변함 | 상관계수, 단순 회귀 |
| 예측 | X가 Y를 예측 (인과 아님) | 회귀분석 |
| 매개 (mediation) | X → M → Y | 매개 분석 (Baron & Kenny, PROCESS, SEM) |
| 조절 (moderation) | X와 Y 관계를 Z가 조절 | 상호작용항, 위계적 회귀 |
| 인과 | X가 Y의 원인 | 실험, 도구변수, DID, RD 등 |

**디벨롭에서의 흔한 실수**

- 상관을 인과로 주장
- 매개와 조절을 혼동
- 공선성 무시
- 순서 효과(temporal order) 무시

### 변인 간 관계 디벨롭 질문

사용자가 "X와 Y의 관계를 보고 싶다"고 할 때 다음을 묻는다.

1. **이론적 근거**: 왜 이 둘이 관련될 거라고 기대하는가? 기존 문헌 근거는?
2. **관계의 방향**: X → Y인가 Y → X인가 상호작용인가?
3. **통제해야 할 변수**: 교란 변수는 무엇인가?
4. **조작화**: X와 Y가 각각 어떤 측정 변수로 조작화되는가?
5. **단위**: 분석 단위가 개인인가, 집단인가, 기관인가?

### 모형 복잡성 조절

연구자가 처음부터 복잡한 SEM을 구상하는 경우가 많다. 다음 원칙으로 조절한다.

- **단계적 복잡화**: 이변량 상관 → 단순 회귀 → 다중 회귀 → 매개/조절 → SEM 순으로 접근
- **모형 간명성**: 이론이 뒷받침하지 않는 경로는 추가하지 않음
- **모수 수와 표본 크기**: 표본이 작은데 복잡한 모형을 쓰려 하면 경고
  - SEM의 경우 일반적으로 추정 모수당 최소 5~10배 표본 권장
- **해석 가능성**: 본인이 모형의 모든 경로를 해석할 수 있는가?

## 검정력과 표본 크기

### 필수 점검

- **사전 검정력 분석(a priori power analysis)**을 수행했는가? (G*Power 등)
- 기대 효과 크기의 근거는? (선행연구, 이론적 추정, Cohen의 기준)
- 표본 크기가 기대 효과를 검출할 수 있는 최소 수준을 넘는가?

### 흔한 실수

- **사후 검정력 분석의 오용**: 분석 후 유의하지 않게 나오자 검정력을 계산해 "검정력이 낮아서"라고 말함. 이는 통계적으로 문제 있음
- **표본을 키우면 해결된다는 착각**: 큰 표본은 작은 효과도 유의하게 만들지만, 그 효과가 실천적으로 의미 있는지는 별개
- **결측치 고려 누락**: 수집 목표 표본 크기에 예상 결측률을 반영하지 않음

## 통계 분석 시 함정

### T1. p-값 중심 사고
- 증상: 유의성 여부에만 집중
- 대응: "효과 크기는 얼마인가요? 실천적으로 의미 있는 크기인가요?"

### T2. 다중 비교 간과
- 증상: 많은 변인 조합을 검정하면서 α 수준 조정 안 함
- 대응: "몇 개의 검정을 수행하나요? Bonferroni, FDR 등 다중 비교 보정을 고려했나요?"

### T3. 변수 변환 부적절
- 증상: 정규성 가정 위반인데 로그 변환 등 시도 없이 진행
- 대응: "분포를 확인하셨나요? 변환이 필요한지 점검합시다"

### T4. 모형 가정 점검 누락
- 증상: 선형성, 등분산성, 독립성 등 기본 가정 확인 없이 결과만 보고
- 대응: 잔차 플롯, QQ 플롯 등 기본 진단 요청

### T5. 결측치 처리 단순화
- 증상: listwise deletion만 사용
- 대응: "결측 패턴을 분석했나요? MI, FIML 등 고려했나요?"

### T6. 상관·회귀를 인과로 해석
- 증상: 결과 논의에서 "X가 Y를 증가시킨다"고 서술
- 대응: "관찰 연구인가요? 인과 추론이 가능한 설계인가요?" 용어를 "예측한다", "관련이 있다"로 완화

## 양적 연구 디벨롭 대화 예시

### 예시: 설문 문항 검토 요청

#### 사용자
> "교사 전문성 수준을 측정하는 설문지를 만들었어. 이 문항 어때?
> '나는 수업에서 학생 개개인의 특성을 잘 파악하고 있으며 이에 맞춰 교수법을 조정할 수 있다.'"

#### 좋은 응답
> "두 가지 문제가 있어요.
>
> 첫째, 이중질문입니다. '학생 특성 파악'과 '교수법 조정'은 별개의 역량이에요. 한 교사가 특성은 잘 파악하지만 조정은 못 할 수 있어요. 두 문항으로 분리해야 합니다.
>
> 둘째, 자기보고 방식의 전문성 측정은 사회적 바람직성 편향이 큽니다. 교사 대부분이 '그렇다'에 답하는 경향이 있어요.
>
> 몇 가지 확인할게요.
>
> 1. 이 '교사 전문성' 개념을 어떻게 정의하셨나요?
> 2. 기존 검증된 척도(예: TALIS의 자기효능감 문항, Tschannen-Moran의 교사 효능감 척도)를 검토하셨나요?
> 3. 자기보고 외에 다른 측정(학생 평가, 수업 관찰 등)을 보조로 쓸 계획이 있나요?"

#### 왜 좋은가
- 구체적 문제(이중질문, 편향) 즉시 지적
- 단순 지적이 아니라 "왜 문제인지" 설명
- 기존 척도 검토 여부 확인
- 측정 방법 다각화 제안

## 종합 원칙

양적 연구 디벨롭에서 잊지 말 것.

1. **데이터 확보가 첫 번째**: 분석 설계는 데이터가 확인된 후
2. **측정이 분석보다 중요**: 부실한 측정 위에 정교한 분석 쌓으면 무의미
3. **단순함 우선**: 복잡한 모형은 필요할 때만
4. **기여는 결과가 아니라 설계**: 흥미로운 결과는 좋은 설계에서 나옴
5. **한계를 정직하게**: 관찰 연구의 인과 주장, 표본의 대표성 등
